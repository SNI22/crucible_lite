## Framework-side changes (not in cloth-grasp's history)

`crucible-core` was extracted as a separate, reusable framework, living at
`~/crucible/core/` (own git repo) and on the `framework-restructure` branch
of `crucible_lite` (PR #9 against upstream `drsiyaoshao-sudo/crucible-lite`).

**Key framework features added this session:**
- `crucible` CLI installable via `pipx install -e ~/crucible/core` — provides
  `crucible init` command
- `crucible init`: run in any project directory; copies templates, sets up
  memory symlink, creates `~/crucible/<basename>` registry symlink, activates
  Article I git hook, execs `claude`
- CLAUDE.md adoption flow: if CLAUDE.md already exists in cwd, it's moved to
  `docs/.adoption/source_CLAUDE.md`, a sentinel is written, and the first
  Claude Code session invokes the new `claude-md-adopter` agent (one-shot)
  to distribute its content across the Crucible doc structure
- Article I hook command uses `$CLAUDE_PROJECT_DIR` (CWD-independent)
- Article I git pre-commit hook shipped in `templates/.githooks/pre-commit`

**Open framework items:**
- PR #9 (`framework-restructure → main` on `drsiyaoshao-sudo/crucible-lite`)
  is waiting on upstream maintainer approval for CI run. Local commits
  beyond what's on the PR exist in `~/crucible/core/` master (the
  `claude-md-adopter` agent + CLAUDE.md adoption flow have NOT been
  pushed to PR #9 yet).
- crucible-core has no GitHub remote of its own yet.
