## Pivot: F_ext as the Contact Force estimate

A301 calibration remains blocked (repeatability — see
[[calibration_blocked_repeatability]]). Decision this session: use the Franka
built-in **F_ext** (`external_wrench_in_base_frame`, flange, base frame) as the
first-pass Contact Force source. This is Amendment-1-sanctioned (Signal
Inventory row 7). It is a model-based flange estimate, not per-contact, and
carries a configuration-dependent bias (~1.6 N, varies with arm pose).

## Control system built (in sim2real_adlros/experiments/cloth_grasp/)

Built on the `arm_client` API (`Robot` + `Gripper`), controller =
`fr3_pose_controller` (Cartesian pose tracker; `default.yaml` param config —
`orientation_pressing.yaml` was tried but spams logs).

- **cloth_pick_place_AtoB.py** — A->B edge pick-place. 6Q multi-stage descent
  (approach +30 mm -> fine +5 mm -> surface -> press `GRASP_DEPTH` below
  surface), grasp, lift, traverse, lower, release, retreat.
  - Motion via **execute_cartesian_traj** (quintic, continuous vel/accel).
  - **Anti-reflex guardrails** adopted from the rolling-testing experiment
    (`src/acoustic_sensing/scripts/rolling_testing/pose/live_rolling_view.py`):
    `MAX_CARTESIAN_SPEED_M_S=0.05`, `MIN_TRAJ_DURATION_S=1.0`,
    `MIN_WAYPOINT_DT_S=0.05`, `SETTLE_SEC=0.5` (dwell so EE velocity -> 0 between
    phases).
  - **Orientation: HOLD_CURRENT_ORIENTATION=True** — waypoint 0 == current pose
    exactly. This fixed a hard crash: commanding the fixed EEF_RPY_DEG (180,0,0)
    from a near-identity start caused an instant reorientation ->
    `cartesian_motion_generator_acceleration_discontinuity` reflex -> the
    franka_server `ros2_control_node` crashed (exit -6). Lift/traverse/lower
    were also split into separate settled trajectories to kill a speed-step
    acceleration spike entering the traverse.
  - **Auto data capture** (no flags): each run writes
    `results/run_<ts>/{pose_wrench.csv, run_config.json, config.yaml}`.
    CSV logs achieved pose, commanded pose, F_ext wrench, gripper width,
    gripper effort, is_ready, active_controller @ 30 Hz. (Rosbag was added then
    removed at operator request — CSV only.)
- **monitor_gui.py** — read-only matplotlib dashboard (2D top-down map, z gauge,
  pose/force readout, status bar via status_bus). Confirmed read-only (never
  sets a target).
- **config.py** — single source of truth; **status_bus.py** — stage channel.

## Folder split (parallel_jaw vs finray)

`experiments/cloth_grasp/` reorganised into two self-contained folders (shared
control scripts, byte-identical; only config.py differs):
- **parallel_jaw/** — `GRASP_WIDTH_M = None` (force-close, `GRASP_FORCE_N=20`).
- **finray/** — `GRASP_WIDTH_M = 0.060` (loose 60 mm gap; finray + press do the
  grasping). Loose-gap path uses `gripper.set_target(width)` instead of
  `close(force)`.

## Gripper force readout — confirmed impossible (sw-advisor verified)

The Franka Hand reports **no** grasp force. sw-advisor verified against code:
libfranka `GripperState` has no force field (only width/max_width/is_grasped/
temperature); the franka_gripper driver **hard-codes** `joint_states.effort` to
`0.0`; the `Grasp.action` result is `success` + `error` only. The new
`gripper_effort_*` CSV columns are all 0.0 (confirmed in data). So the only
gripper "force" is the **commanded 20 N** (unmeasured; actual ~= commanded
within the Hand's force-control accuracy). A measured pinch force needs the
A301-25 pads (blocked).

## Depth sweeps + the preliminary result

Both graspers swept in depth (press below taught surface), F_ext bias-corrected
per run, grasp-hold force (lift-off excluded):

- **Rigid parallel jaw:** grasp succeeds from **2.5 mm -> ~33 N**. Force is
  steady within a grasp (std ~0.3-0.7 N). Slope ~11 N/mm. 0.5 mm steps resolve
  cleanly.
- **Soft finray:** grasp succeeds from **-1 mm -> ~17 N**. Force is noisy within
  a grasp (std ~5-7 N, compliance wander). Slope ~5 N/mm. 0.5 mm steps do NOT
  resolve (step ~2.5 N < noise ~6 N).

**Headline:** the finray grips thin cloth at **~half the contact force** of the
rigid jaw (~17 N vs ~33 N) — the soft-grasper advantage the benchmark exists to
show. (Compare by FORCE, not raw depth: taught surfaces differ and the finray's
was ~1.5 mm high.)

Other findings:
- **Lift-off spike (~45-49 N) is a transient, not table load** — break-away
  stiction + F_ext estimate degrading under acceleration. Once airborne the
  force is ~1 N. The real table force is the grasp-hold value.
- ~40 N press at 3 mm (rigid) is from the stiff position controller commanding
  below a rigid table; sw-advisor recommended impedance control or an
  F_ext-terminated descent to bound it (not yet implemented).

## Open items / next steps

   depth, so no true repeatability error bars. The only clean pair is finray
   -1 mm. Add a repeat-sweep mode.

   across graspers.

   controller`, k_z~600 N/m -> ~1.8 N) or F_ext-terminated descent, so the
